# BookNest 📚

A responsive online bookstore website built with HTML and CSS.

## Technologies

- HTML5
- CSS3

## Features

- Responsive design
- Book categories
- Attractive color gradients
- Hover effects
- Responsive navigation
- Online bookstore layout

## Project Status

This is a front-end practice project.
